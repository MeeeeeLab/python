# 荣誉成绩记录

> Python 主项目 45–60 分钟 · 不表示已经完成。

## 目标

用继承复用学生记录校验，并重写展示方法。

## 分步任务

1. **建立父类**：集中公共字段和校验。（StudentRecord。）
2. **建立子类**：用super初始化并增加project。（HonorsRecord。）
3. **重写与自检**：扩展summary并测边界。（复用父类输出。）

## 运行

```bash
python3 inheritance_records.py
```

## 自测

- 普通与荣誉记录：S01/Amy/88; S02/Bo/95/Robot → `inheritance checks: OK`
- 非法字段：score=101; blank project → `inheritance checks: OK`

```python
class StudentRecord:
    def __init__(self, student_id, name, score):
        student_id, name = student_id.strip(), name.strip()
        if not student_id or not name:
            raise ValueError("id and name are required")
        if isinstance(score, bool) or not isinstance(score, int) or not 0 <= score <= 100:
            raise ValueError("invalid score")
        self.student_id, self.name, self.score = student_id, name, score

    def summary(self):
        return f"{self.student_id} | {self.name} | {self.score}"


class HonorsRecord(StudentRecord):
    def __init__(self, student_id, name, score, project):
        super().__init__(student_id, name, score)
        project = project.strip()
        if not project:
            raise ValueError("project is required")
        self.project = project

    def summary(self):
        return f"{super().summary()} | honors: {self.project}"


def run_checks():
    regular = StudentRecord("S01", "Amy", 88)
    honors = HonorsRecord("S02", "Bo", 95, "Robot")
    assert regular.summary() == "S01 | Amy | 88"
    assert honors.summary() == "S02 | Bo | 95 | honors: Robot"
    assert isinstance(honors, StudentRecord)
    try:
        HonorsRecord("S03", "Cat", 101, "AI")
        raise AssertionError("invalid inherited score accepted")
    except ValueError:
        pass
    try:
        HonorsRecord("S03", "Cat", 90, "  ")
        raise AssertionError("blank project accepted")
    except ValueError:
        pass


if __name__ == "__main__":
    run_checks()
    print("inheritance checks: OK")
```
