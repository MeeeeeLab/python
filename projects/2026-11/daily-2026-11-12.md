# 班级成绩分组统计

> Python 主项目 45–60 分钟；发布内容不表示已经完成。

## 目标

按班级查询对象集合并生成确定的统计结果。

## 先修

- 类与对象
- 列表与字典
- 边界校验

## 分步任务

1. **校验记录**：保存学号、班级和成绩。（提示：拒绝空值和非法成绩。）
2. **按班级分组**：遍历记录并收集每组分数。（提示：setdefault。）
3. **计算统计**：输出count与average。（提示：空成绩册返回{}。）

## 本地运行

```bash
python3 group_statistics.py
```

```python
class StudentRecord:
    def __init__(self, student_id, class_name, score):
        student_id = student_id.strip()
        class_name = class_name.strip()
        if not student_id or not class_name:
            raise ValueError("id and class are required")
        if isinstance(score, bool) or not isinstance(score, int) or not 0 <= score <= 100:
            raise ValueError("invalid score")
        self.student_id = student_id
        self.class_name = class_name
        self.score = score


class GradeBook:
    def __init__(self):
        self._records = []

    def add(self, record):
        if any(item.student_id == record.student_id for item in self._records):
            return False
        self._records.append(record)
        return True

    def summary_by_class(self):
        groups = {}
        for record in self._records:
            groups.setdefault(record.class_name, []).append(record.score)
        return {
            name: {"count": len(scores), "average": sum(scores) / len(scores)}
            for name, scores in sorted(groups.items())
        }


def run_checks():
    book = GradeBook()
    assert book.summary_by_class() == {}
    assert book.add(StudentRecord("S01", "A", 90))
    assert book.add(StudentRecord("S02", "B", 70))
    assert book.add(StudentRecord("S03", "A", 80))
    assert not book.add(StudentRecord("S01", "A", 60))
    assert book.summary_by_class() == {
        "A": {"count": 2, "average": 85.0},
        "B": {"count": 1, "average": 70.0},
    }


if __name__ == "__main__":
    run_checks()
    print("group-statistics checks: OK")
```
