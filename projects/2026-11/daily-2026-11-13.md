# 对象CSV备份恢复

> Python 主项目 45–60 分钟；发布内容不表示已经完成。

## 目标

在对象与CSV字典行之间往返并复用构造校验。

## 先修

- 类与对象
- 列表与字典
- 边界校验

## 分步任务

1. **导出字典行**：实现to_row。（提示：键与表头一致。）
2. **恢复对象**：用classmethod调用构造器。（提示：CSV成绩先转int。）
3. **验证往返**：覆盖空、Unicode和非法值。（提示：使用StringIO。）

## 本地运行

```bash
python3 object_csv_roundtrip.py
```

```python
import csv
import io


class StudentRecord:
    def __init__(self, student_id, name, score):
        student_id, name = student_id.strip(), name.strip()
        if not student_id or not name:
            raise ValueError("id and name are required")
        score = int(score)
        if not 0 <= score <= 100:
            raise ValueError("invalid score")
        self.student_id, self.name, self.score = student_id, name, score

    def to_row(self):
        return {"student_id": self.student_id, "name": self.name, "score": self.score}

    @classmethod
    def from_row(cls, row):
        return cls(row["student_id"], row["name"], row["score"])


def dump_csv(records):
    stream = io.StringIO(newline="")
    writer = csv.DictWriter(stream, fieldnames=["student_id", "name", "score"])
    writer.writeheader()
    writer.writerows(record.to_row() for record in records)
    return stream.getvalue()


def load_csv(text):
    return [StudentRecord.from_row(row) for row in csv.DictReader(io.StringIO(text))]


def run_checks():
    assert load_csv(dump_csv([])) == []
    original = [StudentRecord("S01", "林安", 95), StudentRecord("S02", "Bo", 0)]
    restored = load_csv(dump_csv(original))
    assert [(x.student_id, x.name, x.score) for x in restored] == [
        ("S01", "林安", 95), ("S02", "Bo", 0)
    ]
    try:
        load_csv("student_id,name,score\nS03,Cat,101\n")
        raise AssertionError("invalid score accepted")
    except ValueError:
        pass


if __name__ == "__main__":
    run_checks()
    print("csv-roundtrip checks: OK")
```
