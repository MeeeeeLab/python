# 带Protocol的多格式报告

> Python 主项目 45–60 分钟 · 不表示已经完成。

## 目标

用Protocol写明格式器接口，并补上必要的运行时返回值校验。

## 分步任务

1. **写明接口**：定义含format方法的Formatter Protocol。（方法体使用省略号。）
2. **实现格式器**：文本和CSV类提供兼容方法。（无需继承Formatter。）
3. **验证运行时边界**：拒绝非字符串结果与缺少方法的对象。（注解不会自动检查。）

## 运行

```bash
python3 protocol_reports.py
```

## 自测

- 结构兼容：TextFormatter and CsvFormatter → `protocol checks: OK`
- 错误协作者：bad return, missing format, blank name → `protocol checks: OK`

<details><summary>参考实现</summary>

```python
from typing import Protocol


class StudentRecord:
    def __init__(self, student_id: str, name: str, score: int) -> None:
        student_id, name = student_id.strip(), name.strip()
        if not student_id or not name:
            raise ValueError("student_id and name cannot be blank")
        if isinstance(score, bool) or not isinstance(score, int) or not 0 <= score <= 100:
            raise ValueError("score must be an integer from 0 to 100")
        self.student_id = student_id
        self.name = name
        self.score = score


class Formatter(Protocol):
    def format(self, record: StudentRecord) -> str:
        ...


class TextFormatter:
    def format(self, record: StudentRecord) -> str:
        return f"{record.student_id} | {record.name} | {record.score}"


class CsvFormatter:
    def format(self, record: StudentRecord) -> str:
        return f"{record.student_id},{record.name},{record.score}"


def build_report(record: StudentRecord, formatter: Formatter) -> str:
    result = formatter.format(record)
    if not isinstance(result, str):
        raise TypeError("formatter must return str")
    return result


class BadFormatter:
    def format(self, record: StudentRecord) -> int:
        return record.score


def check_raises(error_type, action) -> None:
    try:
        action()
    except error_type:
        return
    raise AssertionError(f"expected {error_type.__name__}")


amy = StudentRecord("S01", "Amy", 88)
assert build_report(amy, TextFormatter()) == "S01 | Amy | 88"
assert build_report(amy, CsvFormatter()) == "S01,Amy,88"
check_raises(TypeError, lambda: build_report(amy, BadFormatter()))
check_raises(AttributeError, lambda: build_report(amy, object()))
check_raises(ValueError, lambda: StudentRecord("S02", " ", 70))
print("protocol checks: OK")
```

</details>
