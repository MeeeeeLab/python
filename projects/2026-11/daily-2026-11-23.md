# 不可变成绩记录排序器

> 项目 ID：`daily-2026-11-23` · Python 工作日项目约45–60分钟 · 不表示已经完成。

## 目标

用dataclass减少数据类样板代码，并用不可变记录安全表达成绩更正。

## 步骤

1. 声明学号、姓名、成绩字段。
2. 在`__post_init__`维护字段不变量。
3. 用字典拒绝重复学号。
4. 用`replace`生成更正后的新记录。
5. 验收排序、冻结修改、非法输入和缺失学号。

保存为`dataclass_record_project.py`并运行：

```bash
python3 dataclass_record_project.py
```

预期：`dataclass-record checks: OK`。
