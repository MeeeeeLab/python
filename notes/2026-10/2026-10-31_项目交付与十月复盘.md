## 发布版契约

- 以唯一学号管理学生，支持新增、改分、删除和查询。
- 空数据统计返回 `None`；排名按成绩降序、同分按学号升序。
- CSV 使用 UTF-8 与 `newline=""`；缺文件是空状态，坏行返回物理行号。
- 非法输入不得污染旧记录。
- 参考实现只用标准库，不添加数据库、界面框架或第三方测试依赖。

## 可运行参考实现

```python
import csv
from pathlib import Path
from tempfile import TemporaryDirectory

FIELDS = ["id", "name", "score"]


def require_score(score):
    if isinstance(score, bool) or not isinstance(score, int) or not 0 <= score <= 100:
        raise ValueError("score must be an integer from 0 to 100")
    return score


def add_student(records, student_id, name, score):
    student_id = student_id.strip()
    name = name.strip()
    if not student_id or not name:
        raise ValueError("id and name are required")
    if student_id in records:
        return False
    records[student_id] = {"name": name, "score": require_score(score)}
    return True


def update_score(records, student_id, score):
    if student_id not in records:
        return False
    records[student_id]["score"] = require_score(score)
    return True


def delete_student(records, student_id):
    return records.pop(student_id, None) is not None


def statistics(records):
    if not records:
        return None
    scores = [student["score"] for student in records.values()]
    return {
        "count": len(scores),
        "average": sum(scores) / len(scores),
        "highest": max(scores),
        "lowest": min(scores),
    }


def ranking(records):
    return sorted(
        records.items(),
        key=lambda item: (-item[1]["score"], item[0]),
    )


def save_students(path, records):
    with open(path, "w", encoding="utf-8", newline="") as file:
        writer = csv.DictWriter(file, fieldnames=FIELDS)
        writer.writeheader()
        for student_id, student in records.items():
            writer.writerow({"id": student_id, **student})


def load_students(path):
    if not Path(path).exists():
        return {}, []
    records = {}
    errors = []
    with open(path, encoding="utf-8", newline="") as file:
        for line_number, row in enumerate(csv.DictReader(file), start=2):
            try:
                if not add_student(records, row["id"], row["name"], int(row["score"])):
                    raise ValueError("duplicate id")
            except (KeyError, TypeError, ValueError):
                errors.append(line_number)
    return records, errors


def run_checks():
    records = {}
    assert statistics(records) is None
    assert add_student(records, "S02", "Bo", 88)
    assert add_student(records, "S01", "Amy", 95)
    assert not add_student(records, "S01", "Again", 70)
    assert update_score(records, "S02", 95)
    assert not update_score(records, "S99", 80)
    assert [student_id for student_id, _ in ranking(records)] == ["S01", "S02"]
    assert statistics(records) == {
        "count": 2,
        "average": 95.0,
        "highest": 95,
        "lowest": 95,
    }
    with TemporaryDirectory() as folder:
        path = Path(folder) / "students.csv"
        save_students(path, records)
        assert load_students(path) == (records, [])
        path.write_text(
            "id,name,score\nS01,Amy,95\nS02,Bo,bad\nS01,Cy,80\n",
            encoding="utf-8",
        )
        assert load_students(path) == (
            {"S01": {"name": "Amy", "score": 95}},
            [3, 4],
        )
    assert delete_student(records, "S01")
    assert not delete_student(records, "S01")


if __name__ == "__main__":
    run_checks()
    print("release checks: OK")
```

## 为什么这样排序

`ranking` 使用 `(-score, student_id)` 作为键：负分数让高分在前，学号让同分结果固定。Python 官方说明 `sorted` 支持 `key`，且排序稳定；这里再写明第二关键字，输出更容易复现。

## 易错点

| 问题 | 结果 | 修正 |
| --- | --- | --- |
| 同分只按字典当前顺序 | 报告顺序可能不明确 | 把学号写入排序键 |
| 捕获所有文件异常 | 权限错误被伪装为空数据 | 只处理预期行级错误 |
| 更新后才校验 | 失败会污染旧值 | 先校验，再赋值 |
| 空记录直接求平均 | 除以零 | 返回 `None` |
| 为“发布版”提前加入 GUI/数据库 | 增加无关复杂度 | 先交付可运行命令行核心 |
