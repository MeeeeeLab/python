## 可运行验收程序

```python
def linear_search(records, name):
    for index, (student, _score) in enumerate(records):
        if student == name:
            return index
    return -1


def rank_records(records):
    return sorted(records, key=lambda item: item[1], reverse=True)


def run_acceptance():
    records = [("A", 80), ("B", 95), ("C", 80), ("A", 70)]
    assert linear_search(records, "A") == 0
    assert linear_search(records, "Z") == -1
    assert rank_records(records) == [("B", 95), ("A", 80), ("C", 80), ("A", 70)]
    assert records == [("A", 80), ("B", 95), ("C", 80), ("A", 70)]
    assert linear_search([], "A") == -1
    assert rank_records([]) == []


if __name__ == "__main__":
    run_acceptance()
    print("archive acceptance: OK")
```

运行：`python3 archive_acceptance.py`。本次已核对输出：`archive acceptance: OK`。另在临时仓库实际核对了 `git status --short` 与 `git log -1`。

## 容易漏掉的证据

- 排序结果正确，但原列表被修改。
- 同分值正确，但同分记录相对顺序被打乱。
- 重复姓名只测到一次，无法判断返回第一次还是最后一次。
- 工作区仍有未跟踪文件，却以为提交已经完整。
