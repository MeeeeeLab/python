# 2026-10-28｜成绩统计与排序查询

> 阶段：成绩管理系统｜建议用时：约 2.5 小时

## 今日目标

在已有记录上增加只读统计与排名：数量、平均分、最低分、最高分，以及按成绩降序的稳定排名。空记录必须有明确结果，原字典不得被修改。

## 最小设计

`grade_summary(records)` 在空字典时返回 `None`，避免对空序列调用 `min`/`max`。非空时只提取一次成绩列表，再用 `len`、`sum`、`min`、`max`。`ranking(records)` 使用 `sorted(..., key=..., reverse=True)` 返回新列表。Python 官方说明 `sorted` 是稳定的，因此同分学生保持字典插入顺序。

```python
def grade_summary(records):
    if not records:
        return None
    scores = [student["score"] for student in records.values()]
    return {
        "count": len(scores),
        "average": sum(scores) / len(scores),
        "lowest": min(scores),
        "highest": max(scores),
    }


def ranking(records):
    return sorted(
        records.items(),
        key=lambda item: item[1]["score"],
        reverse=True,
    )


def run_checks():
    assert grade_summary({}) is None
    assert ranking({}) == []
    records = {
        "S01": {"name": "Amy", "score": 80},
        "S02": {"name": "Bo", "score": 95},
        "S03": {"name": "Cy", "score": 80},
    }
    assert grade_summary(records) == {
        "count": 3,
        "average": 85.0,
        "lowest": 80,
        "highest": 95,
    }
    assert [student_id for student_id, _ in ranking(records)] == ["S02", "S01", "S03"]


if __name__ == "__main__":
    run_checks()
    print("dashboard checks: OK")
```

运行：`python3 grade_dashboard.py`。本次已核对空数据、三条记录、平均值、最值和同分稳定顺序，输出 `dashboard checks: OK`。

## 复杂度

统计扫描 n 条记录，时间 O(n)，成绩列表占 O(n)。排序时间由内置排序承担，输出新列表占 O(n)。不额外实现排序算法，因为标准库已经覆盖需求。

## 易错点

- 空记录直接调用 `min` 或 `max`。
- 用整数除法思维误判平均值；Python `/` 返回浮点数。
- 为展示排名原地改动业务数据。
- 用集合比较排名，丢失顺序证据。
