## 先写清契约

- 学号、姓名去除首尾空格后不能为空。
- 学号重复时新增失败，旧记录不变。
- 成绩必须是 0–100 的整数；`bool` 虽是 `int` 的子类，也不当作成绩。
- 更新不存在的学号返回 `False`。
- 非法新成绩必须在修改记录前被拒绝。
- 空数据统计返回 `None`，避免除以零。

测试不是多写几次 `print`，而是给输入和预期结果建立稳定对应。Python 的 `assert` 失败会抛出 `AssertionError`；但 `python -O` 会移除断言，所以断言适合自检，不应替代真实输入校验。

## 最小可运行示例

```python
def require_score(score):
    if isinstance(score, bool) or not isinstance(score, int) or not 0 <= score <= 100:
        raise ValueError("score must be an integer from 0 to 100")
    return score


def add_student(records, student_id, name, score):
    student_id = student_id.strip()
    name = name.strip()
    if not student_id or not name:
        raise ValueError("id and name are required")
    if student_id in records:
        return False
    records[student_id] = {"name": name, "score": require_score(score)}
    return True


def update_score(records, student_id, score):
    if student_id not in records:
        return False
    score = require_score(score)
    records[student_id]["score"] = score
    return True


def delete_student(records, student_id):
    return records.pop(student_id, None) is not None


def statistics(records):
    if not records:
        return None
    scores = [student["score"] for student in records.values()]
    return {
        "count": len(scores),
        "average": sum(scores) / len(scores),
        "highest": max(scores),
        "lowest": min(scores),
    }


def run_checks():
    records = {}
    assert statistics(records) is None
    assert add_student(records, " S01 ", " Amy ", 95)
    assert not add_student(records, "S01", "Again", 80)
    assert update_score(records, "S01", 100)
    assert not update_score(records, "S99", 70)
    assert statistics(records) == {
        "count": 1,
        "average": 100.0,
        "highest": 100,
        "lowest": 100,
    }
    try:
        update_score(records, "S01", 101)
    except ValueError:
        pass
    else:
        raise AssertionError("invalid score was accepted")
    assert records["S01"]["score"] == 100
    assert delete_student(records, "S01")
    assert not delete_student(records, "S01")


if __name__ == "__main__":
    run_checks()
    print("project checks: OK")
```

## 这次重构了什么

`require_score` 集中保存成绩规则，新增和更新不再各写一份范围判断。更重要的是，`update_score` 先验证再赋值：即使新成绩非法，旧记录也不会被改坏。这里不引入类、数据库或测试依赖；当前函数和一个自检入口已经覆盖今天的目标。

## 易错点

| 易错写法 | 问题 | 修正 |
| --- | --- | --- |
| `assert 0 <= score <= 100` 作为用户校验 | 优化模式会移除断言 | 明确抛出 `ValueError` |
| 先赋值再校验 | 失败时记录已被污染 | 验证通过后再修改 |
| 空记录直接求平均 | 除以零 | 先返回 `None` |
| 捕获所有异常并继续 | 隐藏真正程序错误 | 只处理预期异常 |
| 为四个函数建复杂类层级 | 增加尚未需要的状态 | 先保留简单函数 |
