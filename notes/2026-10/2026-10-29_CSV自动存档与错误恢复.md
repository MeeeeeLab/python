# 2026-10-29｜CSV 自动存档与错误恢复

> 阶段：成绩管理系统｜建议用时：约 2.5 小时

## 今日目标

把学生字典保存为 CSV，并在启动时加载。缺文件视为首次运行；损坏行和重复学号不静默吞掉，而是返回行号供界面提示。今天只使用 `csv`、`pathlib` 和临时目录测试，不添加数据库或第三方依赖。

## 契约

- `save_students(path, records)`：写入表头和全部记录，UTF-8，`newline=""`。
- `load_students(path)`：返回 `(records, error_lines)`。
- 文件不存在：返回 `({}, [])`。
- 空字段、非整数/越界成绩、重复学号：跳过该行，并把行号加入 `error_lines`。

Python 官方 `csv` 文档建议文件对象使用 `newline=''`，并提供 `DictReader`/`DictWriter` 处理字典行。`Path.exists()` 用于区分首次启动的缺文件情况。

```python
import csv
from pathlib import Path
from tempfile import TemporaryDirectory

FIELDS = ["id", "name", "score"]


def save_students(path, records):
    with open(path, "w", encoding="utf-8", newline="") as file:
        writer = csv.DictWriter(file, fieldnames=FIELDS)
        writer.writeheader()
        for student_id, student in records.items():
            writer.writerow({"id": student_id, **student})


def load_students(path):
    if not Path(path).exists():
        return {}, []
    records = {}
    errors = []
    with open(path, encoding="utf-8", newline="") as file:
        for line_number, row in enumerate(csv.DictReader(file), start=2):
            try:
                student_id = row["id"].strip()
                name = row["name"].strip()
                score = int(row["score"])
                if not student_id or not name or not 0 <= score <= 100:
                    raise ValueError
                if student_id in records:
                    raise ValueError
                records[student_id] = {"name": name, "score": score}
            except (KeyError, TypeError, ValueError):
                errors.append(line_number)
    return records, errors


def run_checks():
    with TemporaryDirectory() as folder:
        path = Path(folder) / "students.csv"
        assert load_students(path) == ({}, [])
        original = {"S01": {"name": "Amy", "score": 95}}
        save_students(path, original)
        assert load_students(path) == (original, [])
        path.write_text("id,name,score\nS01,Amy,95\nS02,Bo,bad\nS01,Cy,80\n", encoding="utf-8")
        assert load_students(path) == (original, [3, 4])


if __name__ == "__main__":
    run_checks()
    print("CSV checks: OK")
```

运行：`python3 csv_storage.py`。本次已核对缺文件、正常往返、坏成绩和重复学号，输出 `CSV checks: OK`。

## 为什么返回错误行号

错误恢复不是假装一切正常。保留成功行同时报告失败行，用户才能修复源文件。今天的最小实现没有做原子替换或备份轮换；当项目真的需要防止写入中断时再加入临时文件替换。

## 易错点

- 忘记 `newline=''`，在部分平台产生额外空行。
- 把所有异常都捕获，连权限错误也伪装成空数据。
- 重复学号覆盖先前记录。
- 遇到一条坏数据就丢掉所有好数据，或反过来静默忽略错误。
