# 2026-10-27｜学生记录增删改查

> 阶段：成绩管理系统｜建议用时：约 2.5 小时

## 今日目标

在昨天的菜单与记录契约上，实现最小 CRUD：新增、查询、修改成绩、删除。用唯一学号作字典键；重复新增和不存在记录都必须有明确返回值。今天仍不加入 CSV、类层次或额外框架。

## 接口契约

| 操作 | 成功 | 失败 |
| --- | --- | --- |
| `add_student` | 写入并返回 `True` | 重复学号返回 `False`，不覆盖 |
| `find_student` | 返回记录 | 不存在返回 `None` |
| `update_score` | 修改并返回 `True` | 不存在返回 `False` |
| `delete_student` | 删除并返回 `True` | 不存在返回 `False` |

字典的键必须唯一；Python 官方教程说明，对已存在的键再次赋值会覆盖旧值，因此新增前必须显式检查。`dict.get` 与 `pop(key, default)` 能用很少的代码表达“不存在”的边界。

## 可运行实现

```python
def add_student(records, student_id, name, score):
    if student_id in records:
        return False
    records[student_id] = {"name": name, "score": score}
    return True


def find_student(records, student_id):
    return records.get(student_id)


def update_score(records, student_id, score):
    student = records.get(student_id)
    if student is None:
        return False
    student["score"] = score
    return True


def delete_student(records, student_id):
    return records.pop(student_id, None) is not None


def run_checks():
    records = {}
    assert add_student(records, "S01", "Amy", 80)
    assert not add_student(records, "S01", "Other", 90)
    assert find_student(records, "S01") == {"name": "Amy", "score": 80}
    assert find_student(records, "S99") is None
    assert update_score(records, "S01", 95)
    assert not update_score(records, "S99", 95)
    assert delete_student(records, "S01")
    assert not delete_student(records, "S01")
    assert records == {}


if __name__ == "__main__":
    run_checks()
    print("CRUD checks: OK")
```

运行：`python3 student_crud.py`。本次已核对新增、重复、查询命中/未命中、修改命中/未命中、删除两次，输出 `CRUD checks: OK`。

## 易错点

- 重复学号直接覆盖原记录。
- 查询函数返回可变记录后，调用方随意修改；本阶段接受这一简单模型，后续需要隔离时再复制。
- 删除不存在记录触发 `KeyError`，但契约要求返回 `False`。
- 把输入、打印和 CRUD 全塞进一个函数，难以测试。
