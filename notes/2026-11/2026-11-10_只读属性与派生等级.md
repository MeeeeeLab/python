# 2026-11-10｜只读属性与派生等级

> **主线延伸安排**：继续练习 property，只增加“由已有数据计算、不能直接赋值”的只读属性，不引入继承。

## 今日目标

- 区分可写属性 `score` 与只读派生属性 `grade`。
- 根据当前分数实时计算等级，而不是保存第二份可能过期的数据。
- 验证 90/80/70/60 等边界。
- 证明没有 setter 的 property 不能被直接赋值。

## 1. 为什么等级不单独保存

若同时保存 `score=90` 与 `grade="A"`，修改分数时可能忘记同步等级。更简单可靠的做法是只保存分数，每次读取 `grade` 时根据当前分数计算。

`grade` 只有 getter，没有 setter，因此调用者可以读取 `student.grade`，却不能写 `student.grade = "A"`。这表达了“等级由分数决定”。

## 2. 可运行示例

```python
class StudentRecord:
    def __init__(self, student_id, score):
        student_id = student_id.strip()
        if not student_id:
            raise ValueError("id is required")
        self.student_id = student_id
        self.score = score

    @property
    def score(self):
        return self._score

    @score.setter
    def score(self, value):
        if isinstance(value, bool) or not isinstance(value, int) or not 0 <= value <= 100:
            raise ValueError("score must be an integer from 0 to 100")
        self._score = value

    @property
    def grade(self):
        if self.score >= 90:
            return "A"
        if self.score >= 80:
            return "B"
        if self.score >= 70:
            return "C"
        if self.score >= 60:
            return "D"
        return "F"


def run_checks():
    student = StudentRecord(" S01 ", 90)
    assert student.grade == "A"
    student.score = 59
    assert student.grade == "F"
    boundaries = {100: "A", 89: "B", 79: "C", 69: "D", 0: "F"}
    for score, grade in boundaries.items():
        student.score = score
        assert student.grade == grade
    try:
        student.grade = "A"
    except AttributeError:
        pass
    else:
        raise AssertionError("read-only grade was changed")


if __name__ == "__main__":
    run_checks()
    print("grade checks: OK")
```

运行 `python3 readonly_grade.py`，已核对等级边界、分数修改后的重新计算以及只读赋值失败：

```text
grade checks: OK
```

## 3. 易错点

| 易错做法 | 正确做法 |
| --- | --- |
| 在构造器保存 `self.grade` | 用只读 property 动态计算 |
| 为 grade 添加任意 setter | 等级不应脱离分数单独修改 |
| 先判断 60 再判断 90 | 从高到低判断，避免 90 被归为 D |
| 忽略 89/79/69 边界 | 明确每个区间并运行自检 |
| 在 grade 中修改 score | getter 只负责读取派生结果 |
