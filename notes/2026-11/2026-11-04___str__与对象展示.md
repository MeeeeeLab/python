## 1. 为什么需要 __str__

没有自定义展示时，直接打印对象通常只得到类型和内部标识。定义 `__str__(self)` 后，`str(obj)`、`print(obj)` 和 f-string 会取得它返回的字符串。它应返回 `str`，而不是直接打印。

## 2. 可运行示例

```python
class StudentRecord:
    def __init__(self, student_id, name, score):
        student_id = student_id.strip()
        name = name.strip()
        if not student_id or not name:
            raise ValueError("id and name are required")
        if isinstance(score, bool) or not isinstance(score, int) or not 0 <= score <= 100:
            raise ValueError("score must be an integer from 0 to 100")
        self.student_id = student_id
        self.name = name
        self.score = score

    def __str__(self):
        return f"{self.student_id} | {self.name} | {self.score}"


def run_checks():
    student = StudentRecord(" S01 ", " Amy ", 95)
    assert str(student) == "S01 | Amy | 95"
    assert f"Student: {student}" == "Student: S01 | Amy | 95"
    try:
        StudentRecord("S02", "", 80)
    except ValueError:
        pass
    else:
        raise AssertionError("empty name must be rejected")
    try:
        StudentRecord("S03", "Bo", 101)
    except ValueError:
        pass
    else:
        raise AssertionError("out-of-range score must be rejected")


if __name__ == "__main__":
    run_checks()
    print("display checks: OK")
```

运行 `python3 student_display.py`，已核对：

```text
display checks: OK
```

## 3. 易错点

| 错误 | 正确做法 |
| --- | --- |
| 在 `__str__` 内 `print` | 用 `return` 返回字符串 |
| 返回列表或数字 | 必须返回 `str` |
| 为展示修改对象状态 | 展示方法只读取状态 |
| 省略构造校验 | 非法对象应在创建时拒绝 |
