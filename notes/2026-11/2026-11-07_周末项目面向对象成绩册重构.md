## 今日目标

- 用 `GradeBook` 管理记录，拒绝重复学号。

## 1. 项目建模

`StudentRecord` 负责“一条记录是否合法和如何展示”；`GradeBook` 负责“多条记录如何存放与统计”。按职责拆成两个小类即可，不引入继承、框架或额外依赖。

## 2. 可运行的周六核心

```python
class StudentRecord:
    def __init__(self, student_id, name, score):
        student_id, name = student_id.strip(), name.strip()
        if not student_id or not name or isinstance(score, bool) or not isinstance(score, int) or not 0 <= score <= 100:
            raise ValueError("invalid student record")
        self.student_id, self.name, self.score = student_id, name, score

    @classmethod
    def from_csv_row(cls, row):
        parts = [part.strip() for part in row.split(",")]
        if len(parts) != 3:
            raise ValueError("row must contain id,name,score")
        return cls(parts[0], parts[1], int(parts[2]))

    def __str__(self):
        return f"{self.student_id} | {self.name} | {self.score}"


class GradeBook:
    def __init__(self):
        self._records = {}

    def add(self, record):
        if record.student_id in self._records:
            return False
        self._records[record.student_id] = record
        return True

    def average(self):
        return None if not self._records else sum(r.score for r in self._records.values()) / len(self._records)

    def lines(self):
        return [str(self._records[key]) for key in sorted(self._records)]


def run_checks():
    book = GradeBook()
    assert book.average() is None and book.lines() == []
    assert book.add(StudentRecord.from_csv_row("S02, Bo, 80"))
    assert book.add(StudentRecord("S01", "Amy", 100))
    assert not book.add(StudentRecord("S01", "Other", 60))
    assert book.average() == 90
    assert book.lines() == ["S01 | Amy | 100", "S02 | Bo | 80"]
    other = GradeBook()
    assert other.lines() == []
    for bad in ("S03,Cat", "S03,Cat,101"):
        try:
            StudentRecord.from_csv_row(bad)
        except ValueError:
            pass
        else:
            raise AssertionError("invalid row accepted")


if __name__ == "__main__":
    run_checks()
    print("oop-gradebook checks: OK")
```

运行 `python3 oop_gradebook.py`，已核对两条正常记录、重复学号、空平均值、非法行及两个成绩册互不共享：

```text
oop-gradebook checks: OK
```

## 3. 易错点辨析

| 易错点 | 正确做法 |
| --- | --- |
| 把记录字典写成类属性 | 在 `GradeBook.__init__` 创建 `self._records` |
| 重复学号直接覆盖 | `add` 返回 `False`，保留原记录 |
| 空成绩册直接除法 | 返回 `None` 表示暂无平均分 |
| 类方法复制全部校验 | 拆分后调用 `cls(...)` 复用构造器 |
| 为排序引入复杂结构 | 输出时对学号键使用内置 `sorted` |
