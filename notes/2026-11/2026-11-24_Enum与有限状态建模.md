## 核心理解

若用任意字符串保存学籍状态，`"active"`、`"Active"`和拼错的`"actve"`都可能混入数据。`Enum`把合法值限制为一组命名成员，例如`ACTIVE`、`SUSPENDED`、`GRADUATED`。

```python
from enum import Enum, auto

class EnrollmentStatus(Enum):
    ACTIVE = auto()
    SUSPENDED = auto()
    GRADUATED = auto()
```

`EnrollmentStatus.ACTIVE.name`是`"ACTIVE"`；精确数值不重要时可用`auto()`。按名称查找写`EnrollmentStatus["ACTIVE"]`，按值查找才使用圆括号。

## 与不可变记录结合

学生资料仍使用`frozen=True`。状态改变时，先检查转换是否合法，再用`replace`创建新对象；原记录保持不变。毕业状态没有可回退目标，能避免散落在代码里的字符串判断。

## 易错点

| 易错理解 | 正确理解 |
| --- | --- |
| Enum成员等于普通字符串 | 成员属于它自己的枚举类型 |
| `Status("ACTIVE")`按名字查找 | 方括号按名字；圆括号通常按value |
| auto值可写进业务规则 | 若数值无业务意义，只依赖成员身份和name |
| 状态可以随意跳转 | 用转换表集中声明允许方向 |
