# 2026-11-05｜类方法与备用构造

> **主线延伸安排**：沿类与对象主线，用一个 `@classmethod` 把 CSV 行转换成对象；不学习继承等额外内容。

## 今日目标

- 区分实例方法的 `self` 与类方法的 `cls`。
- 用 `from_csv_row` 提供备用构造入口。
- 复用 `__init__` 的验证，不复制规则。
- 覆盖字段不足、非数字和越界成绩。

## 1. 类方法解决什么问题

普通构造调用是 `StudentRecord("S01", "Amy", 95)`。若原始数据是一行文本，可提供：

```python
StudentRecord.from_csv_row("S01,Amy,95")
```

`@classmethod` 接收类本身作为第一个参数，惯例名为 `cls`。最后调用 `cls(...) `，让所有合法性规则仍由 `__init__` 负责。

## 2. 可运行示例

```python
class StudentRecord:
    def __init__(self, student_id, name, score):
        student_id = student_id.strip()
        name = name.strip()
        if not student_id or not name:
            raise ValueError("id and name are required")
        if isinstance(score, bool) or not isinstance(score, int) or not 0 <= score <= 100:
            raise ValueError("score must be an integer from 0 to 100")
        self.student_id = student_id
        self.name = name
        self.score = score

    @classmethod
    def from_csv_row(cls, row):
        parts = [part.strip() for part in row.split(",")]
        if len(parts) != 3:
            raise ValueError("row must contain id,name,score")
        student_id, name, score_text = parts
        return cls(student_id, name, int(score_text))

    def __str__(self):
        return f"{self.student_id} | {self.name} | {self.score}"


def run_checks():
    student = StudentRecord.from_csv_row(" S01, Amy, 95 ")
    assert isinstance(student, StudentRecord)
    assert str(student) == "S01 | Amy | 95"
    for bad_row in ("S02,Bo", "S02,Bo,bad", "S02,Bo,101"):
        try:
            StudentRecord.from_csv_row(bad_row)
        except ValueError:
            pass
        else:
            raise AssertionError(f"invalid row accepted: {bad_row}")


if __name__ == "__main__":
    run_checks()
    print("factory checks: OK")
```

运行 `python3 student_from_row.py`，已核对：

```text
factory checks: OK
```

## 3. 易错点

- 漏写 `@classmethod`，导致 `cls` 绑定错误。
- 直接写 `StudentRecord(...)` 而不是 `cls(...)`。
- 在类方法里复制一套分数校验。
- 不检查字段数量，出现难懂的拆包错误。
- 用简单 `split(",")` 冒充完整 CSV 解析器；今日只处理不含逗号转义的练习行。
