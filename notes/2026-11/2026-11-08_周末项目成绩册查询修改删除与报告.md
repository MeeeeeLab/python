## 1. 今天补齐什么

周六已经把职责分成两个类：

- `StudentRecord`：维护一条记录的字段和有效性。
- `GradeBook`：管理多条记录，负责查找、修改、删除与汇总。

今天继续复用已有的类、实例方法和字典，不引入框架或第三方库。

### 两个字典方法

| 方法 | 找到学号时 | 没找到时 |
| --- | --- | --- |
| `records.get(id)` | 返回对应记录 | 默认返回 `None` |
| `records.pop(id, None)` | 删除并返回记录 | 返回 `None`，不抛 `KeyError` |

不要把 `get` 和 `pop` 混淆：前者只查找，后者会改变字典。

## 2. 可运行的周日版本

保存为 `oop_gradebook.py`，运行 `python3 oop_gradebook.py`。

```python
class StudentRecord:
    def __init__(self, student_id, name, score):
        student_id = student_id.strip()
        name = name.strip()
        if not student_id or not name:
            raise ValueError("id and name are required")
        self.student_id = student_id
        self.name = name
        self.set_score(score)

    def set_score(self, score):
        if isinstance(score, bool) or not isinstance(score, int) or not 0 <= score <= 100:
            raise ValueError("score must be an integer from 0 to 100")
        self.score = score

    @classmethod
    def from_csv_row(cls, row):
        parts = [part.strip() for part in row.split(",")]
        if len(parts) != 3:
            raise ValueError("row must contain id,name,score")
        return cls(parts[0], parts[1], int(parts[2]))

    def __str__(self):
        return f"{self.student_id} | {self.name} | {self.score}"


class GradeBook:
    def __init__(self):
        self._records = {}

    def add(self, record):
        if record.student_id in self._records:
            return False
        self._records[record.student_id] = record
        return True

    def find(self, student_id):
        return self._records.get(student_id.strip())

    def update_score(self, student_id, score):
        record = self.find(student_id)
        if record is None:
            return False
        record.set_score(score)
        return True

    def remove(self, student_id):
        return self._records.pop(student_id.strip(), None) is not None

    def average(self):
        if not self._records:
            return None
        return sum(record.score for record in self._records.values()) / len(self._records)

    def report(self):
        if not self._records:
            return "暂无记录"
        lines = [str(self._records[key]) for key in sorted(self._records)]
        lines.append(f"平均分：{self.average():.1f}")
        return "\n".join(lines)


def run_checks():
    book = GradeBook()
    assert book.average() is None
    assert book.report() == "暂无记录"
    assert book.add(StudentRecord.from_csv_row("S02, Bo, 80"))
    assert book.add(StudentRecord("S01", "Amy", 100))
    assert not book.add(StudentRecord("S01", "Other", 60))
    assert book.find("S02").name == "Bo"
    assert book.find("S99") is None
    assert book.update_score("S02", 90)
    assert not book.update_score("S99", 70)
    try:
        book.update_score("S02", 101)
    except ValueError:
        pass
    else:
        raise AssertionError("invalid score accepted")
    assert book.find("S02").score == 90
    assert book.remove("S01")
    assert not book.remove("S01")
    assert book.average() == 90
    assert book.report() == "S02 | Bo | 90\n平均分：90.0"
    other = GradeBook()
    assert other.report() == "暂无记录"
    for bad in ("S03,Cat", "S03,Cat,101"):
        try:
            StudentRecord.from_csv_row(bad)
        except (ValueError, TypeError):
            pass
        else:
            raise AssertionError("invalid row accepted")


if __name__ == "__main__":
    run_checks()
    demo = GradeBook()
    demo.add(StudentRecord("S02", "Bo", 90))
    print(demo.report())
    print("oop-gradebook Sunday checks: OK")
```

运行结果：

```text

平均分：90.0
oop-gradebook Sunday checks: OK
```

## 3. 修改为什么要先校验

`update_score` 先找到记录，再调用 `record.set_score(score)`。而 `set_score` 会先判断分数是不是整数且处于 0–100，检查通过后才赋值。

因此把 S02 从 80 改成 90 后，再尝试改成 101，程序抛出 `ValueError`，原来的 90 保持不变。这比“先写入、发现错误再补救”更容易维护。

## 4. 复杂度与边界

| 操作 | 平均时间复杂度 | 说明 |
| --- | --- | --- |
| `add` / `find` / `update_score` / `remove` | O(1) | 依赖字典平均查找成本；不是无条件的最坏保证 |
| `average` | O(n) | 需要遍历全部记录 |
| `report` | O(n log n) | 对 n 个学号排序，再逐条生成文本 |
| 成绩册存储 | O(n) | 每条记录占一个字典条目 |

| 边界 | 预期行为 |
| --- | --- |
| 空成绩册 | 平均分为 `None`，报告为“暂无记录” |
| 不存在的学号 | `find` 返回 `None`；修改/删除返回 `False` |
| 重复学号 | 添加失败，不覆盖旧记录 |
| 分数为 0 或 100 | 合法 |
| 分数为 101、负数或布尔值 | 拒绝，旧分数不变 |
| 两个成绩册实例 | 各自拥有独立的 `_records` |
