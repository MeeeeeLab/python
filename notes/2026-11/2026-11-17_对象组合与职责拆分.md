# 2026-11-17｜对象组合与职责拆分

> 主线延伸——类与对象 · Python · 建议用时 50–60 分钟 · 发布内容不表示已经完成。

## 今日目标

- 区分“是一个”的继承与“拥有一个”的组合。
- 把邮箱、学生记录、成绩册分别交给合适的类负责。
- 用正常、空集合和非法输入检查对象之间的协作。

## 核心理解

昨天用继承表达“荣誉记录是学生记录”。今天换一种关系：学生记录**拥有一个**联系方式。把 `ContactInfo` 对象放进 `StudentRecord.contact` 就是组合。每个类维护自己的不变量：联系方式检查邮箱，学生记录检查身份与分数，成绩册检查唯一学号并提供集合查询。这样修改邮箱规则时，不必改动成绩册逻辑。

## 可运行示例

```python
class ContactInfo:
    def __init__(self, email: str) -> None:
        email = email.strip()
        if "@" not in email or email.startswith("@") or email.endswith("@"):
            raise ValueError("email must contain text on both sides of @")
        self.email = email


class StudentRecord:
    def __init__(self, student_id: str, name: str, score: int, contact: ContactInfo) -> None:
        if not student_id.strip() or not name.strip():
            raise ValueError("student_id and name cannot be blank")
        if not 0 <= score <= 100:
            raise ValueError("score must be between 0 and 100")
        if not isinstance(contact, ContactInfo):
            raise TypeError("contact must be ContactInfo")
        self.student_id = student_id.strip()
        self.name = name.strip()
        self.score = score
        self.contact = contact

    def passed(self) -> bool:
        return self.score >= 60


class GradeBook:
    def __init__(self) -> None:
        self._records: dict[str, StudentRecord] = {}

    def add(self, record: StudentRecord) -> None:
        if record.student_id in self._records:
            raise ValueError("duplicate student_id")
        self._records[record.student_id] = record

    def passed_emails(self) -> list[str]:
        return [r.contact.email for r in self._records.values() if r.passed()]


def check_raises(error_type, action) -> None:
    try:
        action()
    except error_type:
        return
    raise AssertionError(f"expected {error_type.__name__}")


book = GradeBook()
alice = StudentRecord("S01", "Alice", 88, ContactInfo("alice@example.com"))
bob = StudentRecord("S02", "Bob", 59, ContactInfo("bob@example.com"))
book.add(alice)
book.add(bob)
assert book.passed_emails() == ["alice@example.com"]
check_raises(ValueError, lambda: book.add(alice))
check_raises(ValueError, lambda: ContactInfo("invalid"))
check_raises(ValueError, lambda: StudentRecord("S03", "Cai", 101, ContactInfo("cai@example.com")))
check_raises(TypeError, lambda: StudentRecord("S04", "Dan", 60, "dan@example.com"))
assert GradeBook().passed_emails() == []
print("composition checks: OK")
```

预期输出：

```text
composition checks: OK
```

本次已用 Python 3 实际运行；正常筛选、空成绩册、重复学号、非法邮箱、越界分数与错误联系方式类型均通过。

## 易错点辨析

| 容易误解 | 正确理解 | 小反例 |
| --- | --- | --- |
| 为了复用就让StudentRecord继承ContactInfo | 继承应表达稳定的“是一个”；学生不是联系方式 | `class StudentRecord(ContactInfo)`关系错误 |
| 所有校验都塞进GradeBook | 数据所属的类维护自己的不变量 | 邮箱规则应在ContactInfo内 |
| 组合后不用校验对象类型 | 边界处仍要拒绝错误协作者 | 字符串不能替代ContactInfo实例 |
| 空集合应返回None | 查询多个结果通常返回同类型空容器 | `passed_emails() == []` |
