# 2026-11-09｜属性访问与 property 入门

> **主线延伸安排**：沿面向对象成绩册继续一步，只学习如何让“读取仍像普通属性，修改必须经过校验”；不引入继承或复杂设计。

## 今日目标

- 理解直接公开属性可能绕过校验的问题。
- 用 `@property` 读取分数，用 `@score.setter` 统一校验修改。
- 在构造器中也通过 `self.score = score` 复用同一规则。
- 覆盖正常修改、越界、布尔值和浮点数边界。

## 1. 为什么需要 property

周末成绩册已经能修改分数，但如果任何代码都能直接写 `student.score = -1`，对象就可能进入无效状态。property 让外部仍使用简洁的 `student.score`，实际读取和赋值却会调用 getter 与 setter。

底层值保存为 `self._score`。前导下划线是“内部使用”的约定，不是安全边界；真正保证规则一致的是所有公开修改都经过 setter。

## 2. 可运行示例

```python
class StudentRecord:
    def __init__(self, student_id, name, score):
        student_id, name = student_id.strip(), name.strip()
        if not student_id or not name:
            raise ValueError("id and name are required")
        self.student_id = student_id
        self.name = name
        self.score = score

    @property
    def score(self):
        return self._score

    @score.setter
    def score(self, value):
        if isinstance(value, bool) or not isinstance(value, int) or not 0 <= value <= 100:
            raise ValueError("score must be an integer from 0 to 100")
        self._score = value

    def __str__(self):
        return f"{self.student_id} | {self.name} | {self.score}"


def run_checks():
    student = StudentRecord(" S01 ", " Amy ", 95)
    assert student.score == 95
    student.score = 88
    assert str(student) == "S01 | Amy | 88"
    for bad_score in (-1, 101, True, 88.5):
        try:
            student.score = bad_score
        except ValueError:
            pass
        else:
            raise AssertionError(f"invalid score accepted: {bad_score}")
    assert student.score == 88


if __name__ == "__main__":
    run_checks()
    print("property checks: OK")
```

运行 `python3 property_record.py`，已核对初始分数、合法修改、四种非法分数及失败后原值不变：

```text
property checks: OK
```

## 3. 关键步骤

1. `@property` 把 `score()` 变成读取入口。
2. `@score.setter` 使用同名方法接收赋值。
3. setter 先校验，再写入 `_score`。
4. `__init__` 调用 `self.score = score`，避免复制校验。

## 4. 易错点辨析

| 易错做法 | 正确理解 |
| --- | --- |
| getter 中返回 `self.score` | 会再次调用 getter；应返回 `self._score` |
| setter 中写 `self.score = value` | 会递归调用 setter；应写 `self._score = value` |
| 构造器直接写 `_score` | 会绕过统一校验；应走公开属性 |
| 只检查 `int` | `bool` 是 `int` 的子类，需显式拒绝 |
| 校验失败后先改值再抛错 | 应先验证，失败时保留原值 |
