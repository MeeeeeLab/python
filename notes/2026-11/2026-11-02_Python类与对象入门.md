## 1. 类是蓝图，实例是独立对象

类把数据和操作这些数据的方法放在一起。调用 `GradeBook()` 会创建一个实例；`__init__` 在实例创建后初始化状态。方法的第一个参数通常命名为 `self`，表示当前实例。

```python
book = GradeBook()
other = GradeBook()
```

把 `records` 写成 `self.records = {}`，每个实例都会得到自己的字典。若误写成类属性 `records = {}`，不同实例可能共享同一个可变对象。

## 2. 最小可运行示例

```python
class GradeBook:
    def __init__(self):
        self.records = {}

    def add(self, student_id, name, score):
        student_id = student_id.strip()
        name = name.strip()
        if not student_id or not name:
            raise ValueError("student_id and name must not be empty")
        if isinstance(score, bool) or not isinstance(score, int) or not 0 <= score <= 100:
            raise ValueError("score must be an integer from 0 to 100")
        if student_id in self.records:
            return False
        self.records[student_id] = {"name": name, "score": score}
        return True

    def average(self):
        if not self.records:
            return None
        return sum(record["score"] for record in self.records.values()) / len(self.records)

    def ranking(self):
        return sorted(
            self.records.items(),
            key=lambda item: (-item[1]["score"], item[0]),
        )


def run_checks():
    empty = GradeBook()
    assert empty.average() is None
    assert empty.ranking() == []

    book = GradeBook()
    assert book.add(" S02 ", " Bo ", 88)
    assert book.add("S01", "Amy", 95)
    assert not book.add("S01", "Again", 70)
    assert book.average() == 91.5
    assert [student_id for student_id, _ in book.ranking()] == ["S01", "S02"]

    other = GradeBook()
    assert other.add("S03", "Cy", 77)
    assert "S03" not in book.records

    try:
        book.add("S04", "Dee", 101)
    except ValueError:
        pass
    else:
        raise AssertionError("out-of-range score must be rejected")


if __name__ == "__main__":
    run_checks()
    print("class checks: OK")
```

运行：

```bash
python3 grade_book.py
```

已核对输出：

```text
class checks: OK
```

`book.add("S01", "Amy", 95)` 可理解为把 `book` 作为当前实例交给方法；实际调用时 Python 自动绑定实例。示例还覆盖空成绩册、重复学号、非法成绩、排序和实例隔离。

## 3. 设计取舍

- 状态放在 `__init__` 中，避免实例共享可变数据。
- `add` 返回布尔值表示是否写入；非法输入抛出 `ValueError`。
- 暂不引入继承、属性装饰器或第三方库，先掌握最小对象模型。
- 排名仍复用已学的 `sorted` 与排序键。

## 4. 易错点

1. 方法漏写 `self`。
2. 在 `__init__` 中显式返回非 `None` 值。
3. 把每个实例应独立拥有的字典写成类属性。
4. 只测试正常路径，不检查空、重复和越界输入。
