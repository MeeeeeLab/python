# 2026-11-19｜多态与统一接口

> 主线延伸——类与对象 · Python · 建议用时 50–60 分钟 · 发布内容不表示已经完成。

## 今日目标

- 理解“同一调用、不同实现”的多态。
- 用统一的 `format(record)` 方法替换具体格式器。
- 认识Python鸭子类型，并覆盖缺少接口时的失败边界。

## 核心理解

昨天的组合让对象各负其责；今天进一步让协作者可以替换。函数 `build_report` 不必知道传入的是文本格式器还是CSV格式器，只要对象提供可调用的 `format` 方法即可。Python官方词汇表把这种关注接口而非具体类型的风格称为鸭子类型。它能减少针对类名的条件分支，但方法名、参数和返回值仍要遵守约定。

## 可运行示例

```python
class StudentRecord:
    def __init__(self, student_id: str, name: str, score: int) -> None:
        student_id, name = student_id.strip(), name.strip()
        if not student_id or not name:
            raise ValueError("student_id and name cannot be blank")
        if isinstance(score, bool) or not isinstance(score, int) or not 0 <= score <= 100:
            raise ValueError("score must be an integer from 0 to 100")
        self.student_id = student_id
        self.name = name
        self.score = score


class TextFormatter:
    def format(self, record: StudentRecord) -> str:
        return f"{record.student_id} | {record.name} | {record.score}"


class CsvFormatter:
    def format(self, record: StudentRecord) -> str:
        return f"{record.student_id},{record.name},{record.score}"


def build_report(record: StudentRecord, formatter) -> str:
    return formatter.format(record)


def check_raises(error_type, action) -> None:
    try:
        action()
    except error_type:
        return
    raise AssertionError(f"expected {error_type.__name__}")


amy = StudentRecord("S01", "Amy", 88)
assert build_report(amy, TextFormatter()) == "S01 | Amy | 88"
assert build_report(amy, CsvFormatter()) == "S01,Amy,88"
check_raises(ValueError, lambda: StudentRecord("", "Amy", 88))
check_raises(ValueError, lambda: StudentRecord("S02", "Bo", True))
check_raises(AttributeError, lambda: build_report(amy, object()))
print("polymorphism checks: OK")
```

预期输出：

```text
polymorphism checks: OK
```

本次已用Python 3实际运行；两种格式、空学号、布尔分数和缺少 `format` 的对象均已核对。

## 易错点辨析

| 容易误解 | 正确理解 | 小反例 |
| --- | --- | --- |
| 多态必须写很多继承层次 | Python可直接依赖同名方法 | 两个格式器无需共同父类也能替换 |
| 统一接口意味着输出相同 | 调用方式相同，具体结果可以不同 | 文本与CSV分隔符不同 |
| 鸭子类型完全没有契约 | 契约存在于所需方法、参数与返回值 | 缺少format会抛AttributeError |
| `isinstance(score, int)`会排除True | bool是int的子类，要先显式排除 | True不应被当作分数1 |
