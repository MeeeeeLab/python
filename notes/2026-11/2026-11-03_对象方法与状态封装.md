## 1. 为什么把操作放进对象

昨天的 `GradeBook` 已把数据放进实例。今天进一步把所有状态变化集中到方法中：

- `add`：检查输入后新增；
- `update_score`：验证成功后再修改；
- `remove`：返回是否真的删除；
- `find`、`snapshot`：返回副本。

`_records` 的前导下划线是 Python 约定：调用者应把它当作非公开实现细节，但语言不会阻止直接访问。真正的保护来自清晰接口和不把内部可变对象直接交出去。

## 2. 可运行示例

```python
class StudentRegistry:
    def __init__(self):
        self._records = {}

    @staticmethod
    def _valid_score(score):
        return isinstance(score, int) and not isinstance(score, bool) and 0 <= score <= 100

    def add(self, student_id, name, score):
        student_id = student_id.strip()
        name = name.strip()
        if not student_id or not name or not self._valid_score(score):
            raise ValueError("invalid student record")
        if student_id in self._records:
            return False
        self._records[student_id] = {"name": name, "score": score}
        return True

    def update_score(self, student_id, score):
        if not self._valid_score(score):
            raise ValueError("score must be an integer from 0 to 100")
        if student_id not in self._records:
            return False
        self._records[student_id]["score"] = score
        return True

    def remove(self, student_id):
        return self._records.pop(student_id, None) is not None

    def find(self, student_id):
        record = self._records.get(student_id)
        return None if record is None else record.copy()

    def snapshot(self):
        return {student_id: record.copy() for student_id, record in self._records.items()}


def run_checks():
    registry = StudentRegistry()
    assert registry.find("S01") is None
    assert not registry.remove("S01")
    assert registry.add(" S01 ", " Amy ", 90)
    assert not registry.add("S01", "Again", 70)
    assert registry.update_score("S01", 95)
    assert not registry.update_score("S99", 80)
    assert registry.find("S01") == {"name": "Amy", "score": 95}

    outside = registry.snapshot()
    outside["S01"]["score"] = 0
    assert registry.find("S01")["score"] == 95

    try:
        registry.update_score("S01", 101)
    except ValueError:
        pass
    else:
        raise AssertionError("out-of-range score must be rejected")

    assert registry.remove("S01")
    assert registry.snapshot() == {}


if __name__ == "__main__":
    run_checks()
    print("registry checks: OK")
```

运行：

```bash
python3 student_registry.py
```

已核对输出：

```text
registry checks: OK
```

边界包括空查询、重复学号、不存在的修改与删除、101 分，以及修改外部快照不会影响内部状态。

## 3. 方法绑定与状态变化

通过 `registry.update_score("S01", 95)` 调用时，`registry` 会绑定为方法的 `self`。因此方法能读写当前实例的 `self._records`，不会误改另一个实例。

`snapshot` 对每条嵌套记录再做一次 `copy`。如果只复制最外层字典，里面的学生记录仍会共享。

## 4. 易错点

| 误解 | 正确理解 | 小反例 |
| --- | --- | --- |
| 下划线等于 private | 它是非公开约定，不是权限墙 | 外部仍能写 `obj._records` |
| 验证失败后再恢复 | 应先验证，再修改 | 101 分不能短暂写入 |
| 返回内部字典很省事 | 调用者可绕过方法修改 | `find(...)["score"] = 0` |
| 外层 `dict.copy()` 足够 | 嵌套字典仍需复制 | 快照内部值仍可能共享 |
