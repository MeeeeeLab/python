# 2026-11-28｜周末项目：可靠学生状态报告器

## 今日目标

- 把本周的`frozen dataclass`、`Enum`、自定义异常和ABC组合成一个小系统。
- 用明确的状态转换规则保护旧记录，用异常链保留失败原因。
- 通过统一格式器接口输出稳定排序的文本与CSV报告。

## 项目结构

`StudentProfile`是不可变记录；状态变化通过`replace`创建新对象。任意字符串先由`parse_status`转为枚举，未知名称抛`UnknownStatusError`并以`KeyError`作为`__cause__`。禁止的状态方向抛`InvalidTransitionError`。

`ProfileFormatter`是抽象基类，要求具体格式器实现`format`，并提供共享的记录类型检查。调用端只依赖这一接口：

```python
class ProfileFormatter(ABC):
    @abstractmethod
    def format(self, profiles: list[StudentProfile]) -> str:
        ...
```

## 第一阶段任务

1. 建立ACTIVE、SUSPENDED、GRADUATED三种状态。
2. 校验学号、姓名和状态类型。
3. 实现允许方向与毕业后禁止回退。
4. 实现文本、CSV两种报告并按学号排序。
5. 运行空列表、未知状态、错误格式器与错误元素测试。

## 设计边界

- 相同状态返回原对象，不制造无意义副本。
- 合法转换返回新对象，旧记录不变。
- CSV使用标准库处理转义，不手工拼接逗号。
- 公开仓库只保存题目与参考实现，不保存个人草稿或完成状态。

## 复杂度

状态解析与转换为O(1)。报告先排序n条记录，时间O(n log n)，输出占O(n)空间。
