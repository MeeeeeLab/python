# 2026-11-11｜对象集合与排序查询

> **主线延伸安排**：把已学的类、字典和 `sorted(key=...)` 组合起来，完成不修改原集合的成绩排名查询。

## 今日目标

- 用字典保存多个 `StudentRecord` 对象并拒绝重复学号。
- 用 `sorted` 的 `key` 指定“分数降序、学号升序”。
- 返回新的排序列表，不改变成绩册原来的插入顺序。
- 覆盖空集合、同分和重复学号。

## 1. 对象为什么需要排序键

两个学生对象本身没有默认的大小关系。与其为整个类规定唯一顺序，不如在具体查询中传入 `key`：

```python
key=lambda record: (-record.score, record.student_id)
```

元组先比较负分数，因此原分数越高越靠前；分数相同时再按学号升序。官方排序指南说明 `sorted` 会创建新列表，`key` 为每个元素产生比较键。

## 2. 可运行示例

```python
class StudentRecord:
    def __init__(self, student_id, name, score):
        student_id, name = student_id.strip(), name.strip()
        if not student_id or not name:
            raise ValueError("id and name are required")
        if isinstance(score, bool) or not isinstance(score, int) or not 0 <= score <= 100:
            raise ValueError("invalid score")
        self.student_id, self.name, self.score = student_id, name, score

    def __str__(self):
        return f"{self.student_id} | {self.name} | {self.score}"


class GradeBook:
    def __init__(self):
        self._records = {}

    def add(self, record):
        if record.student_id in self._records:
            return False
        self._records[record.student_id] = record
        return True

    def ranked(self):
        return sorted(
            self._records.values(),
            key=lambda record: (-record.score, record.student_id),
        )


def run_checks():
    book = GradeBook()
    assert book.ranked() == []
    assert book.add(StudentRecord("S03", "Cat", 88))
    assert book.add(StudentRecord("S02", "Bo", 95))
    assert book.add(StudentRecord("S01", "Amy", 95))
    assert not book.add(StudentRecord("S01", "Other", 60))
    assert [record.student_id for record in book.ranked()] == ["S01", "S02", "S03"]
    assert list(book._records) == ["S03", "S02", "S01"]


if __name__ == "__main__":
    run_checks()
    print("ranking checks: OK")
```

运行 `python3 object_ranking.py`，已核对空集合、重复学号、同分规则、排名结果和原字典顺序不变：

```text
ranking checks: OK
```

## 3. 易错点

| 易错做法 | 正确做法 |
| --- | --- |
| 直接 `sorted(records)` | 对象无默认顺序，应提供 key |
| 只写 `key=lambda r: r.score` | 默认升序；高分优先需 `-r.score` 或 reverse |
| 同分没有确定规则 | 加入学号作为第二排序键 |
| 为查询修改原容器 | 使用 `sorted` 返回新列表 |
| 重复学号直接覆盖 | `add` 返回 False 并保留原记录 |
