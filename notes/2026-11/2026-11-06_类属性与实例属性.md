## 今日目标

- 区分 `StudentRecord.total_created` 与 `self.name` 的归属。
- 用类属性记录成功创建的对象数量。
- 避免把可变列表误放在类上造成意外共享。
- 验证两个实例互不覆盖，并处理空字段边界。

## 1. 先理解概念

实例属性通常在 `__init__` 中写成 `self.xxx`，每个实例各有一份。类属性直接写在类体中，由所有实例共享。统计“这个类一共成功创建过多少对象”适合类属性；某位学生的姓名和学号应是实例属性。

类属性若是列表或字典，原地修改会被所有实例看到。每个对象自己的可变数据应在 `__init__` 中创建。

## 2. 跟着代码学

```python
class StudentRecord:
    total_created = 0

    def __init__(self, student_id, name):
        student_id, name = student_id.strip(), name.strip()
        if not student_id or not name:
            raise ValueError("id and name are required")
        self.student_id = student_id
        self.name = name
        StudentRecord.total_created += 1

    def __str__(self):
        return f"{self.student_id} | {self.name}"


def run_checks():
    assert StudentRecord.total_created == 0
    first = StudentRecord(" S01 ", " Amy ")
    second = StudentRecord("S02", "Bo")
    assert StudentRecord.total_created == 2
    assert first.total_created == second.total_created == 2
    first.name = "Ann"
    assert second.name == "Bo"
    try:
        StudentRecord("", "Nobody")
    except ValueError:
        pass
    else:
        raise AssertionError("empty id accepted")
    assert StudentRecord.total_created == 2


if __name__ == "__main__":
    run_checks()
    print("attribute checks: OK")
```

运行 `python3 student_class_attributes.py`，已核对正常创建、实例隔离、空学号和计数不误增：

```text
attribute checks: OK
```

## 3. 易错点辨析

| 误解 | 正确理解 | 小反例 |
| --- | --- | --- |
| 类属性只属于第一个对象 | 它属于类，实例可读取同一值 | 两个实例都读到计数 2 |
| `self.name` 会被所有实例共享 | 每个实例各有自己的 `name` | 修改 first.name 不影响 second |
| 先加计数再校验也没关系 | 构造失败不应计入成功数量 | 空学号抛错后计数仍为 2 |
| 类属性列表能保存每个对象的数据 | 原地修改会意外共享 | 应在 `__init__` 创建列表 |
