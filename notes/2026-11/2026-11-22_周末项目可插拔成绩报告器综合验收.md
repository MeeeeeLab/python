## 今日目标

- 用 `Protocol` 约定“格式器接收记录列表并返回字符串”的结构化接口。
- 把记录校验、集合管理和文本/CSV 输出拆成独立职责。
- 用空集合、重复学号、非法分数和错误格式器完成综合验收。

## 核心理解

`GradeBook` 只负责保存记录，`Formatter` 只负责把一组记录转换为文本。调用端依赖接口结构，而不是依赖某一个具体格式器，因此新增格式时不必修改成绩册。`Protocol` 主要服务静态类型检查；运行时仍要校验格式器的返回值。

CSV 输出使用 `csv.writer` 写入 `io.StringIO`。固定表头和按学号排序让输出可重复核对，也避免手工拼接遗漏引号转义。

## 参考实现

```python
import csv
import io
from dataclasses import dataclass
from typing import Protocol


@dataclass(frozen=True)
class StudentRecord:
    student_id: str
    name: str
    score: int

    def __post_init__(self) -> None:
        object.__setattr__(self, "student_id", self.student_id.strip())
        object.__setattr__(self, "name", self.name.strip())
        if not self.student_id or not self.name:
            raise ValueError("student_id and name cannot be blank")
        if isinstance(self.score, bool) or not isinstance(self.score, int) or not 0 <= self.score <= 100:
            raise ValueError("score must be an integer from 0 to 100")


class Formatter(Protocol):
    def format(self, records: list[StudentRecord]) -> str: ...


class TextFormatter:
    def format(self, records: list[StudentRecord]) -> str:
        if not records:
            return "(empty)"
        return "\n".join(f"{r.student_id} | {r.name} | {r.score}" for r in records)


class CsvFormatter:
    def format(self, records: list[StudentRecord]) -> str:
        stream = io.StringIO(newline="")
        writer = csv.writer(stream, lineterminator="\n")
        writer.writerow(["student_id", "name", "score"])
        writer.writerows([r.student_id, r.name, r.score] for r in records)
        return stream.getvalue()


class GradeBook:
    def __init__(self) -> None:
        self._records: dict[str, StudentRecord] = {}

    def add(self, record: StudentRecord) -> bool:
        if record.student_id in self._records:
            return False
        self._records[record.student_id] = record
        return True

    def export(self, formatter: Formatter) -> str:
        ordered = sorted(self._records.values(), key=lambda r: r.student_id)
        result = formatter.format(ordered)
        if not isinstance(result, str):
            raise TypeError("formatter must return str")
        return result
```

## 边界验收

1. 空成绩册：文本输出 `(empty)`，CSV 仍保留表头。
2. 两条记录逆序加入：两种输出都按学号稳定排序。
3. 重复学号：`add` 返回 `False`，旧记录不被覆盖。
4. 空白姓名、布尔或越界成绩：构造记录时拒绝。
5. 格式器返回非字符串：`export` 抛出 `TypeError`。

## 复杂度

添加记录平均为 O(1)；导出先排序 n 条记录，因此时间 O(n log n)，输出本身占 O(n) 空间。
