## 独立演示顺序

1. 从空记录开始，说明为什么统计返回 `None`。
2. 新增两名学生，演示重复学号被拒绝。
3. 修改一人成绩，查询并生成稳定排名。
4. 保存 CSV，再加载并比较记录。
5. 人为加入坏成绩与重复学号，确认合法行保留、错误行被报告。
6. 删除存在与不存在的学生，说明返回值。

## 最小演示脚本

先把昨日参考实现保存为 `grade_system_release.py`，再保存以下代码为 `demo_release.py`：

```python
from grade_system_release import (
    add_student,
    load_students,
    ranking,
    save_students,
    statistics,
)


records = {}
add_student(records, "S02", "Bo", 88)
add_student(records, "S01", "Amy", 95)
print([student_id for student_id, _ in ranking(records)])
print(statistics(records))
save_students("students.csv", records)
loaded, errors = load_students("students.csv")
print(loaded == records, errors)
```

预期输出：

```text
['S01', 'S02']
{'count': 2, 'average': 91.5, 'highest': 95, 'lowest': 88}
True []
```

## 十月复盘

- 数据组织：字典用唯一学号定位记录。
- 函数契约：成功、失败、异常各有明确含义。
- 文件：CSV 负责跨运行保存，坏行不应静默。
- 算法：查找字典平均为常数级；统计和排序分别需要扫描与排序。
- 测试：正常流程之外，空、重复、缺失、越界和损坏文件同样属于需求。

## 易错点
